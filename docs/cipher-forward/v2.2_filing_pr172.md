## Evidence window

The evidence window is forward. N is fixed at 30 non-empty week-clusters.
There is one look. The window is not extended. A BEAR spell is required
before that look. Any second config uses alpha/4.

Desk rule from Garwe LSR v2 countersign 8c3bd709 A3: BTC 4h EMA50 vs EMA200, +/-1% band; loss as in c90d9e3c. BEAR = EMA50 < EMA200*0.99; BULL = EMA50 > EMA200*1.01; CHOP otherwise. Each week-cluster is labelled by the regime at its Monday 00:00 UTC open. Soko's live label is not used. No-losing-regime gate: each of BULL, BEAR and CHOP needs >=4 non-empty clusters, otherwise the result is INCOMPLETE, not PASS.

The classifier is a pure function of EMA values. It has not been run on any real bars, and it has not been run on anything from 2026.

The fixed 2026 window applies only if the operator approves the carve-out.
That alternative is off by default (`evidence_window.fixed_2026_window.enabled`
is false, and `operator_approved` is false). The forward window is the one
in force. `historical_2026_backtest_opened` stays false.

The paper service is not started by the installer, and `start_time_utc` is
null, so the 30-week clock has not started. The earliest one look is the
30th non-empty ISO week after an operator starts the service, and later if a
week is empty or the BEAR spell has not been observed. There is no calendar
date for that look.
